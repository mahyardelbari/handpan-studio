# هنگ‌پن استودیو (Handpan Studio)

یک پروژه‌ی تمرین هنگ‌درام با HTML، CSS و JavaScript خالص؛ بدون نصب وابستگی و بدون سرور.

## اجرا
1. فایل ZIP را استخراج کنید.
2. `index.html` را با مرورگر مدرن (Chrome، Edge یا Firefox) باز کنید.
3. برای فعال شدن صدا روی یکی از نت‌ها کلیک کنید. هدفون توصیه می‌شود.

## امکانات
- هنگ‌درام مجازی با ۹ ناحیه‌ی قابل لمس و صدای تولیدشده با Web Audio API
- انتخاب چند کوک آزمایشی: D Kurd، A Minor، D Celtic و Integral
- کنترل تمپو، ولوم، طنین و رنگ صدا
- مترونوم و صدای زمینه‌ی پیوسته (drone)
- ثبت نت‌های نواخته‌شده، پخش الگو و ذخیره‌ی الگو در localStorage مرورگر
- کتابخانه‌ی ملودی‌های تمرینی ساده‌شده و الگوهای اختصاصی
- درس‌های مقدماتی و تمرین شنیداری
- بداهه‌ساز پارامتریک با انتخاب حال‌وهوا، پیچیدگی، طول و تمپو
- تم روشن/تیره و میان‌برهای صفحه‌کلید

## نکته‌های فنی
- صدا، سنتز ساده‌ی مرورگری است؛ نمونه‌برداری دقیق از ساز آکوستیک نیست.
- ذخیره‌ی الگو فقط در همان مرورگر و همان دستگاه انجام می‌شود.
- قطعه‌ها نسخه‌های تمرینی ساده‌شده‌اند، نه ترنسکریپشن کامل یا تضمین‌شده.
- برای افزودن قطعه، آرایه‌ی `songs` در `app.js` را ویرایش کنید. هر نت یک عدد از ۰ تا ۸ است؛ صفر نت مرکزی است.
- برای استفاده‌ی آنلاین، کافی است سه فایل پروژه را روی هاست استاتیک قرار دهید.
